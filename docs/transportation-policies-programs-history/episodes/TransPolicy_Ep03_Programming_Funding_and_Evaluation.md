## Transcript

A plan describes a desired network. Programming decides which projects advance, when they advance, and how they are paid for. The source chapter presents programming as the bridge between long-range vision and real construction or service. Because available money is limited, agencies prioritize, fund, schedule, and document projects in instruments such as a transportation improvement program or capital improvement program.

Fiscal constraint matters. A list of desirable projects is not a program unless expected revenues and costs can support it. Funding sources also bring rules about eligible uses, local match, timing, environmental review, and performance. A project can rank highly yet fail to advance because it is not ready, lacks a complete funding plan, or depends on another agency.

Evaluation begins before construction. Agencies define criteria and compare alternatives. Common measures include safety, accessibility, mobility, system condition, reliability, environmental effects, economic effects, equity, and cost effectiveness. A measure must fit the goal. Average vehicle speed does not directly measure whether residents without cars can reach work. Ridership does not by itself describe passenger experience. A benefit-cost result depends on assumptions about time, discounting, risk, and which effects were monetized.

After implementation, performance monitoring asks whether the project delivered what was promised. Evaluation should preserve the baseline, record changes in context, and distinguish output from outcome. Miles of lane installed are an output. Reduced severe collisions or shorter reliable travel times are outcomes.

Torrance application. This section is a separate educational example based on the Torrance General Plan. Imagine a candidate corridor program containing signal work, sidewalk repairs, bus-stop access improvements, and a bicycle connection. A transparent local process would first state the goals, then score each component using published criteria. Safety need, access to schools and jobs, network connectivity, project readiness, lifecycle cost, and availability of outside funds could all matter.

The program should show total cost, funding source, responsible department, dependencies, and expected year. If one grant pays only for construction, design and maintenance still need owners. If a lower-cost access improvement serves people who have few alternatives, an equity criterion may change the ranking.

The City source does not supply this hypothetical scorecard. The example applies the chapter's method. It does not recommend a Torrance capital decision. Current budgets, plans, grant terms, and public records would be required.
